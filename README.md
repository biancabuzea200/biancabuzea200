## Hi there 👋


I'm Bianca or [@buzea200](https://x.com/buzea200?lang=en) on X.


I am the Head of DevRel of [Chronicle Protocol](https://chroniclelabs.org/). As a Web2 FAANG Solutions Architect turned Web3 DevRel, I've been working to onboard developers into the Web3 ecosystem, focusing on user experience and developer engagement. I also founded [DevRel Uni](https://www.devreluni.com/), the first program designed to help individuals start a career in Developer Relations as well as co-organized [Web3 DevRel Summit](https://web3devrelsummit.com/), the first conference for web3 DevRels.

## 🎙️ Talks:
You can find me delivering talks and workshops around the world, in places like the USA, Germany, Spain, Colombia, Netherlands, Poland, Romania, France, and the UK. 🌏
You can see an overview of my previous speaking engagements [here](https://biancabuzea.com/activities/).
